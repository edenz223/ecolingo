# 一句一句 · Yiju Yiju

用自己的音频和字幕，一句一句练跟读。

一句一句是一款桌面语言学习工具，原名 EcoLingo。打开本地音频和字幕，就能听原声、跟着读，再回听自己的录音。练习过程离线可用，无需注册账号，音频和录音都留在你的电脑上。

## 下载安装

**目前尚未发布可直接下载的安装包。** 请留意 [版本发布页（Releases）](https://github.com/edenz223/ecolingo/releases)，安装方式和支持的系统以发布说明为准。

GitHub 上的 **Code → Download ZIP** 下载的是源代码，不能像普通软件一样双击运行。如果你没有编程经验，建议等安装包发布后再使用；想自行构建的用户可以查看[开发指南](docs/development.md)。

## 怎么练？

先听一句原声，再模仿它的发音、重音和节奏读出来，最后听听自己的录音，和原声对照。不用一次练完整篇，遇到难句可以放慢速度、反复练习。

准备好软件后，可以按下面的步骤开始。

### 1. 准备音频和字幕

**还没有练习材料？可以先试试这三组英语对话：**

- 咖啡店点单：练习点饮品、选配料和付款。
- 超市购物：练习询问商品位置和结账。
- 周末计划：练习邀请朋友、约定时间和地点。

示例位于仓库的 [examples/english-shadowing](examples/english-shadowing) 文件夹，包含三组配好的 MP3 音频和 SRT 字幕。在软件中点击「打开课程文件夹」，选择电脑上的这个文件夹即可练习。

**想用自己的材料？** 按下面的方式准备：

把音频和对应的字幕放在**同一个文件夹**，两个文件的名字要相同，只有后缀不同。例如：

```text
我的跟读材料/
  第一课.mp3
  第一课.lrc
  第二课.mp3
  第二课.srt
```

- 音频支持 `.mp3`、`.wav`、`.ogg`、`.aac`、`.flac`、`.m4a`。
- 字幕支持 `.lrc`、`.srt`，需要包含每句话出现的时间。
- 一个文件夹可以放多组材料，每组音频和字幕会成为一节课。

普通文稿、PDF 或没有时间信息的文字不能直接作为字幕使用。仅仅把文件后缀改成 `.lrc` 或 `.srt` 也不行。

### 2. 打开课程

点击首页的 **「打开课程文件夹」**，选择刚才准备好的文件夹，也可以把文件夹直接拖入窗口。导入后会显示字幕，可以从右侧课程列表切换课程。

以后更换材料时，点击顶部的 **「文件」** 打开另一个文件夹。

### 3. 先听一遍

点击底部的播放按钮，或按 **空格键** 开始播放。当前句会高亮显示；点击某一句，可以从那里开始听。

觉得太快时，点击底部的速度按钮（例如 `1x`），选择较慢的速度。

### 4. 开始跟读

打开底部的 **「跟读」** 开关，点击旁边的文字或小箭头，选择 **「先听后读」**，再点击播放。

第一次录音时，如系统询问麦克风权限，请允许使用。听完原声后，底部按钮会变成红色录音状态，这时开始朗读。说完后稍作停顿，软件会自动结束录音并继续练习。

想重新读这一句，按 **R**；想暂停，按 **空格键**。完成的录音会自动保存，点击字幕旁的录音播放按钮，可以听到这一句最新的录音。

建议戴上耳机练习，减少原声被麦克风再次录进去的情况。

## 选择适合自己的练习方式

- **先听后读**：听原声 → 自己读。适合第一次接触材料，先熟悉每句话。
- **听读回听**：听原声 → 自己读 → 自动回听录音。适合边练边对照自己的发音和节奏。
- **先读再听**：先自己读一遍 → 听原声 → 再读一遍 → 自动回听第二遍录音。适合先尝试，再对照原声调整；保存的是第二遍录音。

切换练习方式后，点击播放继续。只想听材料时，关闭「跟读」即可。

## 难句慢慢练

- **重复一句**：在底部的循环模式菜单中选择「单句循环」，设置练习次数。
- **连续练习**：选择「列表循环」，当前课程结束后会继续下一课。
- **专注显示**：点击底部的专注按钮，放大当前句、收起其他界面。鼠标移到底部可显示控制栏，按 **Esc** 退出。
- **回到当前句**：翻看其他字幕后，点击「回到当前句」，继续跟随播放位置。
- **对照原声**：当前句有录音时，按 **B** 或点击句子旁的对比按钮，依次听原声和自己的录音。
- **接着上次练**：下次打开软件时，点击「继续练习」回到上次的位置，再点击播放。

窗口较窄时，部分控件会隐藏；找不到速度或循环按钮时，可以先把窗口拉宽。

## 常用快捷键

打开课程后可以使用以下快捷键，也可以点击顶部「帮助」查看。

| 按键  | 操作                                       |
| ----- | ------------------------------------------ |
| 空格  | 播放 / 暂停；录音时停止当前录音            |
| S     | 开启 / 关闭跟读                            |
| A / D | 上一句 / 下一句                            |
| Q / E | 上一课 / 下一课                            |
| R     | 播放中直接开始录当前句；录音中重新录这一句 |
| B     | 对比当前句原声和最新录音（需要已有录音）   |
| C / X | 加快 / 放慢播放速度                        |
| Z     | 恢复正常速度                               |
| Esc   | 退出专注显示                               |

## 常见问题

### 去哪里找练习材料？

可以先使用上面的三组英语对话，熟悉操作后再换成自己的材料。

可以从自己已有的语言教材、播客或听力材料开始，优先选择附带 `.lrc` 或 `.srt` 字幕的音频。字幕需要与这份音频的内容和时间对应。

软件不会自动生成字幕。如果只有音频和文稿，需要先用字幕编辑工具制作带时间的字幕，再导入练习。

### 打开文件夹后没有课程，或者提示文件不完整？

检查音频和字幕是否放在所选文件夹内，而不是里面的子文件夹；文件名是否完全一致，例如 `第一课.mp3` 要配 `第一课.lrc` 或 `第一课.srt`。也请确认字幕不是空文件，并包含有效的时间信息。

### 字幕乱码，或者和声音对不上？

乱码时可以尝试把字幕重新保存为 UTF-8 编码。时间对不上时，先确认字幕和音频来自同一版本；音频开头多了一段片头，也会让后面的字幕错位，需要在字幕编辑工具中调整时间。

### 麦克风没有反应，或者没读完就停止了？

先检查系统是否允许应用使用麦克风，以及默认麦克风是否选对。打开跟读后还需要点击播放，才会进入练习。

软件会根据声音自动结束录音：说话后静音约 1.2 秒就会停止；一直没有检测到声音时会暂停练习。目前每次录音最长 10 秒，较长的段落建议先在字幕中拆成短句。需要重来时按 **R**。

### 录音会上传吗？保存在哪里？

不会上传。录音保存在这台电脑的应用数据文件夹中，与原始课程材料分开存放；句子旁的按钮播放该句最新的录音，重复练习会保留历史录音。目前没有录音导出或云同步功能。

移动或重命名课程文件不会影响录音关联；修改音频或字幕内容后，软件会把它视为新课程。

### 会自动给发音打分吗？

目前不提供自动评分。你可以回听自己的录音，与原声对照练习。

### 遇到其他问题怎么办？

可以在 [问题反馈页（Issues）](https://github.com/edenz223/ecolingo/issues) 描述你的系统、操作步骤和看到的提示；附上截图会更方便排查。提交反馈需要 GitHub 账号，日常使用软件不需要账号。
