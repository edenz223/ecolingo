# 课程导入与计时

- 课程按文件名配对音频（MP3/WAV/OGG/AAC/FLAC/M4A）和字幕（LRC/SRT）。只扫描文件夹第一层的文件，按自然顺序排序（「2」在「10」前）；子文件夹和其他文件（封面、文本等）忽略，只有缺少配对的音频或字幕才列入「课程文件不完整」提示。
- 课程文件以 `{ name, path }` 普通对象传给渲染进程，`path` 为所在文件夹。课程键为音频完整路径（`src/utils/lesson-library.ts` 的 `lessonKey`），用于列表 key、录音计数和继续上次。
- 打开方式：系统对话框、标题栏/菜单「文件」、空状态按钮、抽屉的「打开其他文件夹」，或把文件夹（或其中任一文件，按其所在文件夹处理）拖入窗口。拖放路径由 preload 的 `webUtils.getPathForFile` 取得，主进程校验为绝对路径并可读后再扫描。
- 打开后没有任何成对课程时提示「这个文件夹里没有成对的音频和字幕」；拖入项无法读取时提示「无法打开拖入的项目」。正在播放的课程不中断，列表高亮按课程键重新定位。
- 句子格式 `{ start, end, text }`，单位秒。LRC 的 `end` 取下一句 `start`；最后一句用音频时长补齐。
- 保留 Unicode 与编码检测；字幕按文本渲染，不作为 HTML 执行。
- 导入须处理空文件、错误时间戳、缺失配对和特殊文件名，错误提示可操作且不崩溃。
- 句子切换使用 20 ms 轮询音频时钟，最后一句由音频结束回调处理。
- 切换课程时取消过期异步任务，防止旧会话干扰。
- 切换课程立即停止并释放上一课的音频与录音资源，但保留其句子（`releaseLesson(true)`），在新课程音频 `onload` 时一次性替换；加载失败或彻底释放时才清空句子。切换期间 `sound` 为空，播放、导航和快捷键均不响应。
