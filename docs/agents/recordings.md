# 录音存储

- 录音保存到 `userData/recordings`（音频文件 + `index.sqlite`），每条有 UUID。
- 课程标识由音频和字幕内容哈希生成，移动文件夹后仍可关联。主进程按两个文件的「路径 + 大小 + 修改时间」缓存标识（`createLessonIdentityCache`），文件变化后重新计算。
- 课程列表的「已录 N 句」来自 `recordings:count`（同一课程中有录音的不同句子数）。渲染进程逐课查询、随到随显示，切换文件夹时丢弃过期结果；当前课程在保存录音后即时更新。
- 存储操作在主进程，先写音频再原子替换索引。录音须同时关联课程和句子标识。
- 录音保留在本地，不提供导出或云同步。
