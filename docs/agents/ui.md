# 界面与交互

## 设计理念

Minimal desktop UI。单色中性色板，纯平不透明表面，微妙 1 px 边框，中等圆角，紧凑间距（基准 4 px），排版驱动，克制用图标，**无渐变、无毛玻璃（`backdrop-filter`）、无重阴影、无 `inset` 高光**。控件和菜单使用中文。

## 设计令牌

颜色、字号、间距、圆角、阴影、焦点等令牌的取值以 `src/css/app.scss` 的 `:root`（浅色）、`@media (prefers-color-scheme: dark)`（深色）及 `src/css/quasar.variables.scss` 为准，不在文档中重复。

- 组件只使用令牌，不写死颜色（录音珊瑚红 `#de5555`、关闭按钮红色、白色滑块与声波除外，两种外观相同）。
- 文字令牌在对应背景上 ≥ 4.5:1（`--ink-faint` 仅用于禁用态和占位符）；改颜色须重新核对对比度。
- `--accent` / `$primary` 为经典蓝，用于实色主按钮、开关、指示条；`.text-primary` / `.text-negative` 改用 `--active-ink` / `--danger-ink` 保证小字可读。
- 边缘栏（标题栏、课程标题栏、底栏、抽屉）用 `--bg-surface` + 1 px `--border` 分隔、无阴影；菜单、对话框用 `--bg-raised` + `--border-strong` + `--shadow-lg`；工具提示 `--shadow-sm`；空状态 `--bg-sunken`；字幕面板透明。
- 所有可聚焦控件在 `:focus-visible` 时显示 `--focus-ring`；Quasar focus helper 和水波纹已全局隐藏，不得移除这些 outline 规则。
- 滚动条 6 px、轨道透明；字幕面板隐藏原生滚动条。

### 外观切换

标题栏「视图」菜单：「外观：跟随系统 / 浅色 / 深色」，偏好 `theme`。渲染进程通过 `window:setTheme` 设置 `nativeTheme.themeSource`，CSS 只用媒体查询。主进程在 `userData/appearance.json` 保留一份，启动时先应用，窗口背景色（`#ffffff` / `#1a1918`，与 `--bg-base` 一致）首帧即正确。`:root` 声明 `color-scheme: light dark`。

### 字幕字号

「视图」菜单：「字幕字号：小 / 中 / 大」，偏好 `subtitleSize`，写入 `<html data-subtitle-size>`，只替换 `--text-sentence*`、`--text-zen*` 令牌。菜单选择后保持打开便于对比；菜单打开时空格和 R 快捷键暂停。

## 按钮与开关

- 默认 flat 按钮：透明底，hover `--bg-hover`，active `--bg-active`；非圆形按钮 `--radius-md`。
- 主播放按钮：48 px 实色 `$primary` 圆形；空状态 CTA 同色实底。
- 跟读开关：flat 圆形图标按钮 `record_voice_over`，`role="switch"` + `aria-checked`，`aria-label`「跟读」，提示「开启跟读 · S」/「关闭跟读 · S」。关闭态图标 `--ink`；开启态 `--active-ink` + `--active-bg`。开启后右侧出现 28 px 圆形 `expand_less`（`aria-label`「选择练习方式」），点击弹出「练习方式」菜单（先听后读、听读回听、先读再听）。关闭跟读时收起菜单并隐藏箭头。
- 窗口宽度 ≤ 600 px 时，底栏把循环与速度控件收进「更多」（`more_horiz`）菜单，其余控件单排；普通与专注模式规则相同。

## 图标

仅用 Material Icons，18–20 px，颜色跟随文字令牌，不加彩色底圈（错误对话框的 `warning` 也是裸图标）。新增图标前确认确有必要。侧边栏开关为 1 px 线条自定义 SVG。

能用图标表达的操作不写文字：图标按钮必须有 `aria-label` 和悬停提示（`HintTooltip.vue`），有快捷键时写在提示里。菜单项、对话框和空状态的说明仍用文字；桌面菜单「文件 / 视图 / 帮助」保留文字。

## 播放与录音状态

主播放按钮统一呈现状态，没有悬浮麦克风浮层：

- 录音态切换为珊瑚红胶囊声波（三条白色圆角柱）。柱高跟随平滑后的麦克风音量 `level`（0–1，由 `voice-activity.ts` 按阈值以上的对数响度计算，上升快、回落稍慢），在静止与最高之间变化：轻声只动一点，大声音节才到顶；两侧柱重放中间柱约 40 / 100 ms 前的音量，形成向外扩散的波动；高度过渡 80 ms。减少动态效果偏好下不连续起伏，只在检测到人声时切到固定中等高度。
- 录音时点击主按钮或按空格立即停止当前录音并重置该句。

## 专注模式

- 顶栏与抽屉隐藏，舞台占满窗口。当前句放大（`--text-zen`），相邻句 `--text-zen-neighbor`、透明度 0.4，**保留模糊** `filter: blur(2.5px)`。
- 底栏布局与普通模式一致，平时 `translateY(100%)` 隐藏，鼠标移到底部感应区时滑出。
- 底栏隐藏时，录音按钮从底部中央独立浮现（`bottom: 16px`），录音结束后隐退。
- `Escape` 或底栏按钮退出。有菜单打开时 Esc 先关菜单。

## 练习状态

开启跟读且已加载课程时显示（`PracticeStatus.vue`，由 `practice-status.ts` 推导）：

- 步骤随练习方式变化：先听后读「听原声 · 跟读」；听读回听「听原声 · 跟读 · 回听」；先读再听「尝试 · 听原声 · 跟读 · 回听」。当前步骤用 `--active-*` 高亮，录音中用 `--recording-*`；已完成 `--ink-muted`，未到 `--ink-faint`；等待开始时不高亮。
- A/B 对比进行时（无论是否开启跟读）显示「原声 · 我的录音」两步。
- 步骤旁不显示说明文字（准备、录音、保存、回听由高亮步骤、录音按钮声波和指示条颜色表达），只有提醒类状态显示文字。
- 没检测到语音时显示 `--warning-ink`「没听到声音，按空格重试」2 秒。
- 状态紧贴当前句：普通模式是当前句条目的第二行（与句子左对齐）；专注模式在当前句正下方居中（间距 12 px）。开启跟读后这一行始终占位，空闲时 `visibility: hidden`，开始、暂停时句子不跳动。≤ 600 px 时只显示当前步骤。
- 当前句左侧 2 px 指示条随状态变色：默认 `--accent`，录音中 `--recording-ink`，提醒 `--warning-ink`。

## 按键提示

键盘触发 C / X / Z、Q / E、S 时，底部中央（`bottom: 96px`）显示约 1.2 秒胶囊提示（`ActionHud.vue`），如「速度 1.1x」「第 3 课 · 课程名」「跟读已开启 · 先听后读」。鼠标操作不显示。同一提示用于打开文件夹的反馈。150 ms 淡入淡出，减少动态效果时无过渡。

## 空状态与课程列表

- 空状态按情况切换：有可继续位置时「继续上次的练习」+「继续练习」；已有课程时「选择一课开始」+「从第一课开始」；没有课程时「开始今天的跟读」+「打开课程文件夹」。没有课程时说明「选择或拖入包含音频和字幕的文件夹」。有课程时另有「打开其他文件夹」。
- 首次打开课程时，主按钮转圈和「正在打开课程…」延迟 300 ms 才出现，加载快时不闪。
- 抽屉顶部只显示文件夹名（超长省略），还没有文件夹时显示「课程列表」；右侧 `folder_open` 打开其他文件夹。
- 课程多于 15 节时显示筛选框，按名称不区分大小写过滤；无匹配显示「没有匹配的课程」。
- 有录音的课程在名称下显示 14 px `mic` 图标 + 句数（等宽数字，悬停「已录 N 句」）。
- 拖入文件时全窗口遮罩 + 居中卡片「松开以打开课程文件夹」，遮罩不拦截指针事件。

## 字幕列表

- 当前句 `--text-sentence-active` / 600，背景 `--active-bg`，左侧 2 px `--accent` 指示条；hover `--bg-hover`。
- 句子切换自动滚动居中；用户手动滚动后暂停跟随，标题栏显示 `my_location` 圆形图标按钮（提示「回到当前句」）。
- 课程标题栏的句子计数只写「3 / 20」。
- 切换课程时保留上一课的列表直到新课程就绪，不出现空状态：加载超过 150 ms 时列表淡到 0.45 并停止响应指针，录音按钮和句子计数隐藏；减少动态效果时无过渡。
- 有录音的句子右侧显示对比（`compare_arrows`）和播放/停止录音（`play_circle` / `stop_circle`）；对比进行中对比按钮变 `stop_circle`，播放录音按钮隐藏。操作列固定 84 px，文本宽度一致。
- 句子获得焦点后 ↑ / ↓ 移动焦点，Enter 播放该句；方向键同时暂停自动跟随。

## 循环与速度菜单

- 循环菜单（`LoopModeList.vue`）：单句循环带「− 次数 +」步进器，0–99，0 显示 `∞`；可直接输入或滚轮增减。
- 速度菜单（`PlaybackRateList.vue`）：「− 倍速 +」步进器（步长 0.1，范围 0.1–4）+ 预设；与预设相等时高亮。
- 两者同时用于底栏和「更多」菜单，逻辑集中在 `playback-options.ts`。

## 对话框

遮罩 `--backdrop`，无模糊；卡片内边距 24 px。错误对话框按来源区分标题：课程加载/播放失败「课程无法播放」并提供「重新选择文件夹」；麦克风与录音问题「录音提示」。

## Electron 窗口与标题栏

- 应用图标（「影子」）：深色圆角方底 `#1c1917`，白色声波是原声，向右下错开的 `#2f9be8` 声波是跟读的影子。母版 `src-electron/electron-assets/icons/icon.svg`；`icon.png` / `icon.ico` / `icon.icns` 和 `public/icons/favicon-32x32.png` 由它导出，改图标先改母版再重新导出。标题栏「EcoLingo」左侧显示 16 px 图标（`favicon-32x32.png`）。
- 右上角最小化、最大化/还原、关闭（关闭红色悬浮）；双击空白处切换最大化；保留原生阴影与缩放边框（`thickFrame: true`）。
- 标题栏菜单：「文件」（打开文件夹）、「视图」（外观、字幕字号）、「帮助」（快捷键）。
- 专注模式下标题栏及窗口按钮隐藏。

## 快捷键

空格 播放/暂停 | S 跟读 | A/D 上/下一句 | Q/E 上/下一课 | B 对比原声与录音 | C/X 加/减速 | Z 重置速度 | Esc 退出专注显示

- 快捷键对话框用 `<kbd>` 两列列出全部按键，与上面保持同步。
- 当前句没有录音时按 B 提示「这句还没有录音」。
- 播放中按 R 跳过播放并录制当前句；录音中按 R 打断重录，开始前播放短提示音，声波刷新一次（减少动态效果时不播放动画）。Ctrl+R 保留刷新行为。
- 忽略可编辑控件；未加载课程时禁用。
- 点击句子或按钮后空格仍控制播放；在捕获阶段处理按下和松开，长按只切换一次。输入框、菜单与对话框保留自身键盘交互。
