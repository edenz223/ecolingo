# 本地录音与备份

完成跟读后，录音会自动写入 Electron 用户数据目录下的 `recordings/`：

- `index.sqlite`：课程、句子、录音时间、格式和校验信息。
- `audio/`：每次录音的独立音频文件。重复练习会保留历史版本。

点击顶部的 **录音记录** 可查看并播放全部历史录音，即使原课程暂时不可用。句子旁的播放按钮播放该句最新录音。

## 导出与恢复

- **导出备份**：选择本地保存位置，将全部录音及 SQLite 索引打包为 ZIP。单个备份支持最多 512 MB（解压后）。
- **恢复备份**：选择此前导出的 ZIP。恢复前校验音频完整性；记录合并到现有库，相同记录去重，缺失或损坏的音频可从备份修复。
- **合并音频**：按句子顺序，将当前课程每句最新录音合并为一个 WAV 文件（单声道、24 kHz、16 位 PCM，最长 30 分钟）。未录音句子会跳过。WAV 用于收听，恢复记录请使用 ZIP 备份。

录音备份不包含原课程音频或字幕，请另外保存课程文件。恢复后重新打开相同内容的课程，即可关联录音；移动或重命名文件不影响关联，修改课程文件内容会产生新的课程身份。

导出与恢复会暂停练习；尚未完成的跟读录音会被取消。请在一句录音完成后操作。所有录音与备份均在本地处理，不会上传。
